# Where's my money

A free, shared budget for friends and family, in the "every dollar a job" style: income goes into
Ready to assign, you give it out to categories each month, leftovers carry over, and overspending
stays red until you cover it.

Built the same way as [Trip Tab](https://github.com/HuangJon/trip-tab): plain HTML, CSS and
JavaScript modules, GitHub Pages, and Firebase on the free plan.
